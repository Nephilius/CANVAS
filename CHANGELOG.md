# Changelog

## 0.1.5

- Added Focus Overlay Mode for image items with a separate always-on-top reference window
- Added image transform controls inside the overlay: pan, zoom, reset, lock / unlock
- Added pass-through mode for interacting with apps behind the overlay
- Added perspective grid overlays and richer snapping behavior on the board
- Added expanded visual intelligence features around image palettes and board organization
- Switched Windows distribution to portable-first output

## 0.1.4

- Published a clean current installer base to avoid patching from older unstable installs

## 0.1.3

- Added improved image import coverage
- Added New Session flow
- Added custom right-click menus
- Added board swatch extraction from image items

## 0.1.2

- Improved patch staging and update progress behavior

## 0.1.1

- Introduced manual `.zip` patching support

## 0.1.0

- Initial production slice with board shell, persistence, canvas, import, inspector, autosave, and command history
