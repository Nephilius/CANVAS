# Canvas Studio 0.1.6

## Highlights

- Portable-first Windows release flow
- Quick Draw board sketching
- Connector strings between frames and references
- Inline canvas text editing
- Multi-window support
- Session file save and reopen flow

## Added

- Quick Draw mode with board-level persisted strokes
- Brush color, brush size, and smoothing controls
- Connector mode for linking frames and references with curved strings
- Connector color editing through right-click and inspector controls
- Inline editing directly on the canvas for text-backed items
- Open New Window support
- Clear Session with confirmation
- Compact low-zoom icon rendering for non-image references

## Improved

- Top bar styling toward a flatter desktop-menu look
- Frame behavior so contained items move and scale with the frame
- Pen / Windows Ink handling for draw mode
- Session save/open flow into reusable session files
- Import dialog behavior and import feedback
- SQL runtime asset loading for packaged portable builds

## Removed / Changed

- Removed the visible perspective grid workflow from the current product surface
- Disabled broken drag-drop import until it can be reintroduced safely
- Shifted release delivery to portable-only Windows builds

## Notes

This version is the current portable baseline and includes the latest local UI, board, and persistence work.

### Why drag-drop is disabled right now

Drag-drop import is temporarily disabled in 0.1.6 because the desktop file-drop path was not behaving reliably enough in the packaged Electron build. In some cases the board would miss Explorer drops, return incomplete file information, or silently fail depending on runtime context. Instead of leaving a half-working import path in the product, the release keeps the stable import methods:

- Import from the file picker
- Paste images from the clipboard

Drag-drop will be reintroduced later after the runtime path handling is reworked and validated properly in packaged builds.
