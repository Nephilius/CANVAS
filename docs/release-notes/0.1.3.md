# Canvas Studio 0.1.3

## Highlights

- Expanded image import coverage
- New Session flow
- Custom context menus
- Palette extraction to swatch items

## Added

- Support for more common desktop image formats
- New Session creation flow
- Custom board and item right-click menus
- Image color extraction into board swatches

## Improved

- Better creative board interaction through image-specific context actions
- Cleaner submenu handling for color extraction

## Notes

0.1.3 was the release where the app started feeling more like a true creative board tool instead of a basic reference shell.
