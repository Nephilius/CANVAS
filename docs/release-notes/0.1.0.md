# Canvas Studio 0.1.0

## Highlights

- First production slice of the desktop app

## Added

- Desktop shell with workspace, project, and board model
- Infinite canvas foundation
- Reference import pipeline
- Inspector panel
- Autosave
- Command history / undo-redo
- Board items such as notes, frames, swatches, and images

## Notes

This was the foundational release that the later feature passes built on.
