# Canvas Studio 0.1.5

## Highlights

- Focus Overlay Mode for image references
- Overlay transform controls and pass-through mode
- Stronger board study and reference workflows

## Added

- Focus Overlay Mode as a separate always-on-top Electron window
- Overlay pan and zoom controls for the image inside the floating window
- Overlay lock / unlock for image transform
- Overlay opacity control
- Pass-through mode for interacting with software behind the overlay
- Safety shortcut to disable pass-through without getting stuck

## Improved

- General board-side visual intelligence workflows
- Portable-oriented Windows release direction

## Notes

0.1.5 established the floating cross-app reference workflow that later versions refined.
